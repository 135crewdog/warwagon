# research

The public documents War Wagon's flight model is built from, uploaded by the owner, and what's been made from them. `docs/research-plan.md` says what each document is for and how charts are read.

- `*.pdf`: the documents, named by their register ID (`A1-tm73250.pdf`), as listed in `docs/research-plan.md` section 2.
- `charts/`: the chart images cut from the documents, one per figure, named `<document>-fig<number>.png`.
- `check/`: the overlay images, made by `overlay.py`, with the digitized points drawn over each chart.
- `overlay.py`: a dev-only script, not part of the app (it will be added with the first chart).
